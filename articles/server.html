Development server

You may need a local development server. You can use github-pages-router CLI as a local development server to simulate the GitHub Pages environment.

Install github-pages-router package, for example with 

npm install github-pages-router --save-dev

Then add this to your package.json scripts 

"start": "github-pages-router",

And of course you can launch it with 

npm start

Notice that you may also need to add an homepage attribute to your package.json. It is required if your website is of second kind: check the setup page for details.
